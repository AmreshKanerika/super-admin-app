How applications work
  • An application reaches organizations through the subscription plans that include it — use Plans on a row to add it to plans or remove it.
  • Design-time and runtime limits are set per plan, under Subscription Plans.
  • The scopes set here are the permissions those plans' roles grant.
  • Once an organization uses an application it is locked: live users' permissions come from its scopes, so editing and deleting stay disabled until it's removed from their plans.
  • Applications nested under Migration are migration applications. Each needs its migration details — what the migration needs to run. Organizations receive a copy when the application reaches them through a plan, so set them up before adding it to plans.
